# UltOd client Godot Classic 3D MMORPG Template

This repository is a template for the Classic 3D client branch of the UltOd MMORPG stack.

## Current state

- Repository is created and ready as a GitHub template.
- Topics and metadata are set.
- No client gameplay code is included yet.
- Client integration is paused until Zig server version alignment is validated.

## Purpose

Use this repo as the starting point for a Godot Classic 3D MMORPG client implementation, with naming and licensing conventions matching the UltOd ecosystem.

## Planned work (not yet applied)

- Network client foundation
- Scene architecture baseline
- Build/run instructions
- Content and asset pipeline notes

## Status policy

Everything pushed in this repository is currently documentation only.
