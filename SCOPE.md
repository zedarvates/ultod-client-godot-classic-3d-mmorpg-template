# Public Scope

## In scope after approval

- Original minimal Godot Classic 3D project structure
- Third-person camera and movement examples
- Keyboard, mouse and controller abstractions
- Scene and UI architecture documentation
- Server-authoritative client interface contracts
- Local development and build documentation
- Synthetic fixtures containing no production data

## Out of scope

- Existing Ultimate Odycer client code
- Any historical or current Zig server implementation
- Production protocols, endpoints, credentials or infrastructure
- Commercial, moderation, administration or billing components
- Player data and telemetry
- Unreviewed game content, brands or third-party assets
- Compatibility claims without named evidence

## Publication rule

Every future contribution must pass [docs/PUBLICATION-CHECKLIST.md](docs/PUBLICATION-CHECKLIST.md). Compatibility with the canonical server must be documented before the first network implementation.
